# parkwithme

A simple web app for finding parking in Vancouver.

## Features
- Interactive map of street parking and garages (Leaflet)
- Filter by neighborhood
- "Free right now" toggle
- Locate me + nearest spots
- Directions to Google Maps

## Structure
- `index.html` — page structure
- `style.css` — styles
- `app.js` — logic + embedded parking data

## Run
Open `index.html` in a browser (or serve the folder with any static server).

## Data
Street parking segments and garage locations are embedded in `app.js`.
